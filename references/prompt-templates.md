# AI 知识周报可复用提示词模板

使用前将 `{当前周次}` 替换为真实周次；仅在准备下一周目录时使用 `{下一周周次}`。模板不授予超出当前用户请求的写入、归档、确认或交付权限。

## 1. 资料盘点与分析

```text
读取项目规则文件、10_周报需求/{当前周次}/周报需求.md，以及
20_原始工作副本/{当前周次}/目录下全部可读取资料。

目标：完成本周资料盘点与主题分析；本阶段只分析资料，不要撰写周报正文。

只根据当前工作副本实际存在的内容分析，不修改原始工作副本。无法确认的来源、时间、事实或信息标记“无法确认”。根据本周需求判断资料与主题的重要程度。

新增 30_知识盘点与周报规划/{当前周次}/weekly_source_analysis.md，使用以下结构：
# Weekly Source Analysis
## 1. 本周资料概览
## 2. 资料盘点
## 3. 重复、冲突与异常资料
## 4. 跨来源主题分析
## 5. 本周候选重点主题
## 6. 待人工确认事项
```

## 2. 生成周报初稿

```text
读取项目规则文件、10_周报需求/{当前周次}/周报需求.md、
30_知识盘点与周报规划/{当前周次}/weekly_source_analysis.md；必要时回查
20_原始工作副本/{当前周次}/全部资料。

先规划本周知识周报的结构与重点，再直接生成周报。内容必须以本周资料为依据，不得编造资料无法支持的事实、数字或结论。合并重复信息；冲突、缺失和无法确认内容标记“待确认”。完成后执行基础证据检查，能依据现有资料修正的问题直接修正。

首次生成时，新建两份相同文件：
- 40_周报生成/{当前周次}/周报.md
- 90_版本归档/{当前周次}/周报_初始版.md

确认目标不存在，不覆盖已有 Review 内容。
```

## 3. 人工 Review 与内容确认

```text
根据以下 Review 意见继续修改：40_周报生成/{当前周次}/周报.md

只根据本周现有资料修改；不得添加资料无法支持的新事实。若 Review 意见涉及事实变化，先指出冲突或证据缺口。无法确认内容继续保留“待确认”。一般修改只更新当前周报，不创建额外版本。
```

只有用户明确确认周报可进入分享版处理后，才可使用：

```text
将当前 40_周报生成/{当前周次}/周报.md 原样复制为
90_版本归档/{当前周次}/周报_内容确认版.md。
不重新改写，不新增、删除或改变事实与结论。
```

## 4. 生成与 Review 分享版

```text
读取项目规则文件与 40_周报生成/{当前周次}/周报.md。

以周报为事实与结论基线，先规划团队阅读版，再生成分享版。可调整顺序、标题、段落和表格；删除内部备注、编辑说明、AI 工作痕迹以及内部链接格式。合并重复表达，保持专业、简洁、易扫描。

不得改变已确认的核心事实、数字、日期与结论，也不得添加现有资料无法支持的新事实。新发现的冲突、缺口或无法确认事项必须保留供人工 Review。

首次生成时，新建两份相同文件：
- 40_周报生成/{当前周次}/周报_分享版.md
- 90_版本归档/{当前周次}/周报_分享版.md
```

## 5. 分享确认后的最终交付

仅在用户明确确认分享版可作为最终交付内容后使用：

```text
读取项目规则文件与 40_周报生成/{当前周次}/周报_分享版.md。

先将当前分享版原样复制为：
90_版本归档/{当前周次}/周报_分享确认版.md。

若当前环境具备文档生成能力，再生成：40_周报生成/{当前周次}/周报.docx。
内容以分享版为准，不新增、删除或改变已确认核心内容；保持标题、段落、列表与表格清晰，并验证文档可正常打开。

若当前环境具备目标云文档平台的已授权工具，可根据分享版创建私人文档；不得自动扩大权限、公开分享或伪造链接。若没有该能力，保留本地交付并如实说明限制。
```

## 6. 自动初稿模式

```text
按 ai-knowledge-weekly-report 的自动初稿模式执行：确定 {当前周次}，读取本周周报需求和原始工作副本，生成 weekly_source_analysis.md，规划并生成周报.md 与周报_初始版.md，完成基础证据检查，并在不存在时准备 {下一周周次} 的五个空目录。

随后停止等待人工 Review。不得创建内容确认版、分享版、分享确认版、Word 或云端文档；不得模拟人工确认。
```
